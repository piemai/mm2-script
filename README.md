# 🔥 Kyuzxc MM2 Mod Menu (iPad & Mobile Edition)

Isang custom script at mod menu para sa **Murder Mystery 2 (MM2)** sa Roblox, na ginawa para maging smooth at madaling gamitin sa mga mobile executors tulad ng **Delta iOS**.

---

## 📋 Features

* **Role ESP:** Madaling nakikita kung sino ang *Murderer* (Kulay Pula) at *Sheriff* (Kulay Asul).
* **Gun Drop ESP & Teleport:** Nakaka-detect at nagpapakita ng tag sa nahulog na baril, kasama ang instant teleport button para mabilis itong makuha.
* **Responsive Sidebar UI:** Malinis, adjustable, at touch-friendly menu interface na may violet accent theme.

---
